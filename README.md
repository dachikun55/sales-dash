# 営業ダッシュ！
日本語・スマートフォン対応の無料営業ダッシュボード。外部通信・依存ライブラリ・会員登録・DB不要。

## 起動
Python 3があるPCで、このフォルダ内から `python3 -m http.server 8080 --bind 0.0.0.0` を実行し、http://localhost:8080 を開きます。ES ModulesのためHTMLの直接ダブルクリックではなくHTTPで開いてください。

## iPhoneで確認
1. PCとiPhoneを同じWi-Fiにつなぐ。
2. 上記サーバーを起動。Windowsは `ipconfig`、macOSはネットワーク設定でPCのローカルIPアドレスを確認。
3. Safariで `http://PCのIPアドレス:8080` を開く。接続できない場合はPCのファイアウォールでローカルネットワークから8080への接続を許可。
4. 「この月にサンプルを読み込む」、売上の変更、休日追加、キャンペーン編集、再読込後の保存、CSV書出しと読込を確認。
5. Safariの共有メニューから「ホーム画面に追加」も利用可能（オフライン動作の保証なし）。

## GitHub Pagesで無料公開
GitHubで**新しい公開リポジトリ `sales-dash`**を作成し、このフォルダのファイルをmainブランチのルートにアップロード。既存プロジェクトは使用しません。
Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save。
公開URLは `https://ユーザー名.github.io/sales-dash/`。SafariでこのURLを開けばPCの常時起動は不要です。公開されるのはコードのみで、入力した売上データはブラウザ内に保存されます。

## 仕様
- 月ごとに目標・実績・前年同月売上・休日・キャンペーン最大3件を保存。
- 達成率 = 実績 / 目標 × 100。目標0の場合は「—」。前年同月比 = (現在実績 / 前年同月売上 − 1) × 100、前年0は「—」。当月途中の実績と前年同月全体を比較する点に注意。
- 残り営業日は端末の現地日付の**今日を含む**。土日・指定休日を除外。過去月は0、将来月は全営業日。祝日は自動取得せず手動登録。
- 不足額は0を下限。日次必要額は切り上げ。営業日0で未達の場合は「算出不可」。
- CSVはUTF-8 BOM付き。全月の売上・休日・キャンペーンを出力。読込は形式検査後に確認し全データを置換。他形式のCSVは未対応。
- localStorage使用。別端末や別URLとは同期しません。Safariのプライベートモード・ストレージ削除・保存制限に注意しCSVをバックアップ。
- キャンペーン実績は月間実績に自動加算しません（重複集計を避けるため）。

## テスト・設計
`npm test` （Node.js 18以上）。`core.js` は計算・検証・CSV、`app.js` はUIと保存、`style.css` は表示。PROの機能・保存方式を追加する際はこの責務を分離したまま拡張できます。無料MVPに課金処理や外部APIはありません。月3,000円以上の利益は販売価格・利用者数・運用費に依存し、このMVP自体では収益化しません。
