# 営業ダッシュ！ Ver.2.1

会社・商品ごとの営業目標を、売上明細から自動集計する日本語の無料ダッシュボード。iPhoneとPCに対応。外部API・有料サービス・会員登録・サーバー・DB不要。GitHub Pagesで配信できるHTML/CSS/JavaScriptの静的アプリです。

## 4タブで操作

- **ホーム**：表示月と会社・商品フィルター（すべて／未分類／個別）を選び、月間・年間実績、目標達成率、進捗グラフを確認。ランキングは月全体を比較し、フィルターとは独立しています。
- **売上入力**：日付と金額、必要な分類を選択して保存。表示月の売上履歴から編集・削除。
- **目標管理**：全体・会社・商品・会社×商品の月間／年間目標とキャンペーンを設定。年間と月別目標の整合性も確認。
- **設定**：管理方法、年度開始月、会社・商品の登録・名称編集、休日、CSVバックアップ、旧データ参照。

iPhoneでは下部に固定したタブバーで切替。画面下の安全領域を確保し、最後の項目も操作できます。PCは上部ナビゲーション。キーボードの左右矢印・Home・Endでタブを選択できます。

## 使い始める

1. https://dachikun55.github.io/sales-dash/ をSafariなどで開く。
2. 「設定」で管理方法を選び保存。必要な場合だけ会社・商品を登録。
3. 「売上入力」で日付・金額と必要な分類を入力。
4. 「目標管理」で目標を登録し、「ホーム」で進捗を確認。
5. 定期的に「設定」からCSVを書き出してバックアップ。

新しく使う場合の初期設定は「全体のみ」。既存のVer.2保存データと旧Ver.2 CSVは「会社×商品別・1月開始」として読み込み、今までの入力方法を維持します。

## 管理方法とデータ保持

| 管理方法 | 新しい売上の入力項目 |
| --- | --- |
| 全体のみ | 日付・金額 |
| 会社別 | 日付・会社・金額 |
| 商品別 | 日付・商品・金額 |
| 会社×商品別 | 日付・会社・商品・金額 |

使わない入力欄は非表示・非必須です。新しい売上の省略した分類は空欄として保存します。管理方法を切り替えても保存済み明細は変更しません。過去の明細を編集する際、今の管理方法で非表示の分類も保持します。

分類が空欄、null、または省略された明細も読み込み可能。未分類を全体売上には含め、具体的な会社・商品の目標に配賦しません。会社だけ登録した明細はその会社と全体に、商品だけ登録した明細はその商品と全体に集計します。旧未分類明細は編集時も未分類のまま金額を訂正できます。

会社・商品の名前はIDを変えずに編集するため、既存の明細・目標・キャンペーンの関連付けが維持されます。

## 年度設定

年度の開始月を1〜12月から選択。年度は開始年で表示します。例：4月開始の2026年度は2026年4月〜2027年3月。ホームの年間実績、年間目標の実績、月別目標の整合性に同じ期間を使います。

変更時は確認を表示します。年間目標の金額と売上明細は保持し、設定年度の期間で再集計します。月間目標・キャンペーンの指定期間は変更しません。開始月1月なら以前と同じ暦年集計です。

「Ver.2のサンプルを追加」は設定タブから利用できます。既存データは削除しませんがサンプル明細も実績に加算されます。不要なサンプル明細・目標は編集・削除できます。

## 個別目標の仕様

- 全体、会社別、商品別：月間・年間目標を独立して設定。
- 会社×商品別：月間目標を設定。年間の内訳目標は今回の対象外。
- 同じ対象・期間の保存は上書き更新。会社別目標と商品別目標を一致させる必要はありません。
- 各目標の実績は売上明細から計算。達成率は実績 ÷ 目標 × 100。不足額は max(目標 − 実績, 0)。目標0は達成率「—」。
- 年間目標は設定した開始月から12か月の年度で集計。
- 年間目標と同じ対象の月別目標合計・差額・設定月数・未設定月数を表示。未設定月がある場合は差額0でも整合完了とは扱いません。
- 上位目標と内訳目標を合算しません。全体目標は会社・商品・会社×商品目標の合計から自動変更されません。

## 売上と集計

- 1件の売上明細は、固有ID・日付・必要な分類・円単位の非負整数金額を持ちます。会社・商品は空欄も保持できます。
- 全体実績は明細を1回ずつ合計。会社別と商品別の各ビューは同じ明細を条件で絞った表示です。ビューの金額を合算しないため、全体への二重加算はありません。
- 複数商品がある取引は商品ごとの金額に分けて登録し、取引総額を別行で重ねて登録しないでください。
- 売上明細の編集・削除は全体・会社・商品・内訳・キャンペーンのすべてに反映。
- 月間は売上日の年月、年間は売上日が属する設定年度で集計。将来日を登録した場合もその月・年・条件に一致する実績に含みます。
- 現在の無料版では返品・負の売上は未対応。訂正は元の明細の編集または削除で行います。
- 残り営業日は端末の現地日付の今日を含みます。土日・指定休日を除外。祝日は手動登録。不足額 ÷ 営業日数を1円単位で切り上げ。営業日0かつ未達は「算出不可」。
- 前年同月比は当月の明細実績と前年同月の明細実績を比較。前年実績0は「—」。月途中では前年の全月実績との比較になります。

## キャンペーンとランキング

- キャンペーンは最大3件。名称・対象会社（すべて可）・対象商品（すべて可）・開始日・終了日・目標を設定。
- 日付は両端を含み、会社と商品を両方指定した場合はAND条件。実績は設定期間全体の一致明細のみ。表示月によって期間実績は変えません。
- キャンペーン同士の対象が重なる場合はそれぞれに実績を表示しますが、キャンペーン実績を全体に足しません。
- 会社別・商品別ランキングは表示月、キャンペーン別は各設定期間全体で比較。実績金額順／達成率順を選択可能。
- 「未達の目標だけ表示」で未達会社・商品・キャンペーンを絞り込み。目標未設定の対象は未達扱いにせず「目標未設定」と表示。

## 初期版データの保持

- 初期版の `sales-dash:v1` 保存領域を変更・削除しません。
- Ver.2は `sales-dash:v2` を使用。初回のみ初期版の全データをコピーして保存し、全体月間目標・休日を引き継ぎます。
- 初期版の実績やキャンペーンには日付・会社・商品の内訳がないため売上明細に自動変換しません。Ver.2と旧実績は合算しません。
- 「設定 → データ管理 → 初期版の保存データ」で旧データを確認できます。`legacy.html` から初期版の画面・CSV出力も利用できます。
- 初期版画面で後から行った変更はVer.2へ自動同期されません。旧CSVの読込でVer.2内の旧データ参照を更新できます。現在のVer.2明細・目標は保持されます。
- 保存済みデータが壊れている場合は上書きを停止します。Ver.2 CSVで復元できます。別タブの更新を検出した場合は再読込してから編集してください。

## CSVとブラウザ保存

- Ver.2 CSVはUTF-8 BOM、`version,type,data` の3列。data欄に各会社・商品・売上明細・目標・キャンペーン・休日・管理方法／年度設定・旧データをJSONで保存するバックアップ形式です。
- Ver.2 CSV読込は検証・確認の後に全データを置換。追記でないため同じCSVを何度読んでも明細は増えません。
- 初期版CSVは旧データ参照だけを置換し、明細に加算しません。設定行のない旧Ver.2 CSVにも対応します。保存領域とデータversionは2を維持し、設定情報を追加しています。
- 任意の表計算CSVや他アプリの売上CSVは未対応。入力値・参照・重複ID・対象期間・金額・キャンペーン上限を検証してから保存。
- localStorageに保存。端末・ブラウザ・URLが異なるとデータは別です。プライベートモード、ブラウザデータ削除、容量制限に備えてCSVを保管してください。
- ローカル確認URLからPages URLへ移す場合はCSVで移行します。

## GitHub Pages

Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save。
`index.html` と `.nojekyll` をルートに配置済み。外部ライブラリやビルドは不要です。公開するのはコードだけで入力した営業データはブラウザ内に保存されます。

## PC・iPhoneでローカル確認

Python 3があるPCで、このフォルダから `python3 -m http.server 8080 --bind 0.0.0.0` を実行。PCでは http://localhost:8080 を開きます。
PCとiPhoneを同じWi-Fiに接続し、Safariで `http://PCのローカルIP:8080` を開きます。接続できない場合はPCのファイアウォール設定を確認。HTMLの直接ダブルクリックではES Modulesが動作しないためHTTPで開いてください。
